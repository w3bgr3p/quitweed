# Задача: генерация ежедневных фактов для cannabis quit bot

## Что нужно сделать

Сгенерировать YAML-файлы с научными фактами для каждого периода отмены каннабиса.
Каждый файл — отдельный период, факты ротируются по дням внутри периода.

Генерировать **по одному периоду за Task** через субагентов — не всё сразу.

---

## Структура выходного файла

Файл: `facts/facts_period_{N}.yaml`

```yaml
period: 1
days: "1-3"
title: "Острая фаза"
facts:
  - day: 1
    scientific: "Точный научный тезис. Термины не объяснять."
    plain: "То же самое бытовым языком. Метафоры приветствуются. 2-4 предложения."
  - day: 2
    ...
```

| Период | Дни | Фактов |
|--------|-----|--------|
| 1 | 1-3 | 3 |
| 2 | 4-7 | 5 |
| 3 | 8-14 | 11 |
| 4 | 15-30 | 22 |
| 5 | 31-60 | 25 |
| 6 | 61-90 | 20 |
| 7 | 90+ | 20 |

Для периодов длиннее количества фактов — бот будет циклить. Это нормально.

## Промпт для субагента (передавать дословно, подставляя данные периода)

```
Ты генерируешь ежедневные научные факты для Telegram-бота сопровождения отмены каннабиса.

Период: {days} — {title}
Научный контекст периода: {context}

Задача: напиши {count} фактов. Каждый факт — два поля:

scientific: точный научный тезис. Используй термины без объяснений. 1-2 предложения.
plain: то же самое бытовым языком. Можно метафоры. Без слов "эндогенный", "везикул", "агонист" и подобных без объяснения. 2-4 предложения.

Формат plain: сначала что происходит, потом почему это важно для человека который бросил.
Пример готового факта:
  scientific: "Анандамид — эндогенный агонист CB1-рецепторов, синтезируется по требованию из мембранных липидов в ответ на активность нейронов."
  plain: "Твой мозг умеет производить собственную версию того что делал THC. Выделяется когда бегаешь, влюбляешься, слушаешь музыку. THC занимал его место годами. Сейчас мозг заново учится производить его сам."

Требования:
- Факты не должны повторять друг друга и не должны повторять основной контент периода
- Каждый факт про отдельный механизм, систему или молекулу
- Тон: нейтральный, научный, без патернализма
- Язык: русский
- plain не должен содержать необъяснённые научные термины
- Не использовать слова: "помни", "молодец", "держись", "всё получится"

Ответь только валидным YAML без markdown-блоков.
```

## Порядок выполнения

```
FOR period IN [1, 2, 3, 4, 5, 6, 7]:
    1. Взять контекст периода из этого файла
    2. Сформировать промпт
    3. Вызвать субагента
    4. Получить YAML
    5. Валидировать:
       - правильное количество фактов
       - каждый факт содержит scientific и plain
       - plain не содержит необъяснённых терминов из списка: эндогенный, везикул, агонист, апрегуляция, downregulation, мезолимбический, ноцицептивный
    6. При провале валидации — повторить субагента
    7. Сохранить в facts/facts_period_{N}.yaml
    8. Лог: "Period {N} done — {count} facts"

После всех периодов:
    8. Собрать facts/all_facts.yaml — объединить все файлы в один массив
```

## Валидация plain (запрещённые необъяснённые термины)

Если любой из этих терминов встречается в поле `plain` — факт невалиден, переделать:

`эндогенный`, `везикул`, `агонист`, `антагонист`, `апрегуляция`, `downregulation`,
`мезолимбический`, `ноцицептивный`, `глутаматный`, `GABAергический`, `серотонинергический`,
`дофаминергический`, `норадренергический`, `холинергический`

В `scientific` — все термины разрешены.
